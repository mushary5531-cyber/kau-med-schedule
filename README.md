# جدولي — KAU Faculty of Medicine Schedule

موقع بسيط (HTML/CSS/JS بدون أي build step) يعرض:

- **السنة الثالثة**: جدول أسبوعي تفصيلي (8 أسابيع) لمقرر Breathing & Circulation Module، تختار مجموعتك (A1-A4 / B1-B4) ويعرض لك جدولك فقط.
- **السنة الأولى والثانية**: نظرة عامة على التقويم الأكاديمي والمقررات لكل فصل.
- ثنائي اللغة (عربي / إنجليزي)، ويحفظ اختيارك محليًا (localStorage) عشان يفتح على جدولك مباشرة في المرة الجاية.

⚠️ **غير رسمي** — الجدول تم بناؤه يدويًا من التعاميم الرسمية الصادرة من كلية الطب. في حال أي تعارض، الجدول الرسمي الصادر من الكلية هو المعتمد.

## البنية

```
index.html
assets/style.css
assets/app.js
data/overview.json          # تقويم + مقررات السنوات 1-3
data/schedule-3rd-year.json # الجدول التفصيلي للسنة الثالثة
```
